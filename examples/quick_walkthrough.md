# Quick Walkthrough (Synthetic)

> **SYNTHETIC EXAMPLE:** Portfolio demonstration artifact only.

This walkthrough shows how to read the synthetic intake and follow the decision-support workflow.

## 1) Read the synthetic intake
Open [`synthetic_input.json`](synthetic_input.json) and review all four diagnostic modules:
- Context & starting point.
- Work style.
- Frustration/ambiguity tolerance.
- Expectations/resources.

## 2) Derive qualitative signals
Translate intake content into non-scored signals, for example:
- strong structure preference,
- low ambiguity tolerance,
- limited weekly hours,
- practical short-term objective.

## 3) Apply elimination logic
Use [`../docs/decision-logic.md`](../docs/decision-logic.md) to remove misaligned paths first, then keep viable options with rationale.

## 4) Follow workflow stages
Map the case through [`../docs/workflow.md`](../docs/workflow.md):
Intake -> Signal normalization -> Elimination -> Draft report -> Human review -> Final report.

## 5) Structure the report output
Confirm the report includes:
- recommended path,
- eliminated paths + rationale,
- alternatives,
- conditional next steps,
- explicit human review reminder.

## 6) Compare with synthetic output
Review [`synthetic_output.md`](synthetic_output.md) as an example final format.

Use this as a portfolio illustration, not as an automated decision pipeline.
